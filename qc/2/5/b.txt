# QC2.5 Simon's Algorithm

This skill introduces Simon's algorithm, which demonstrates an exponential separation between quantum and classical query complexity for a specific type of hidden function. Learners study how quantum superposition, interference, and phase kickback are combined to identify a secret bit string encoded in a black-box function. Emphasis is placed on executing the algorithm and interpreting the computational outcome.

## Requirements

* [[skill-tree:qc:1:3:b]]
* [[skill-tree:qc:2:1:b]]

## Learning Outcomes

* Describe the problem solved by Simon's algorithm and its classical query complexity.
* Explain how superposition, interference, and phase kickback are used to reveal the hidden bit string.
* Execute Simon's algorithm step by step for a given oracle.
* Calculate and interpret the measurement outcomes to determine the secret string.
