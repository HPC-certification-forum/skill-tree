# SD1.2.2.1.1 Shared Memory architecture

Shared memory programming relies on hardware optimizations and the use of multicore systems. Similarly, architecture optimizations like memory prefetches and direct storage access are also highly useful in optimizations.

Technically, GPU are also considers a shared memory system, since its global memory is shared between all cores, but here, they are classified under accelerator cards.

## Learning Outcomes

* Describe the architecture and operation of shared-memory multiprocessor systems.
* Explain how files and file systems are structured and accessed in shared-memory environments, also including direct storage access.
* Apply best practices for protecting data and processes in shared-memory environments, both in memory and storage applications.
* Describe the security issues related to shared-memory environments, especially in memory access.
* Describe structured parallelism models (e.g., fork-join, worksharing) and their benefits for code clarity and scalability.
