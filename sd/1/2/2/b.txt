# SD1.2.2 Shared Memory Systems

Understand the concepts of Shared Memory Programming (SMP) and deploy different strategies to manage synchronizations, dependencies, pipelining, and vectorization.

Additionally, investigate threading implementations using different methods and incorporate different hardware instructions. Similarly, use OpenMP as well as other language extensions and programming models such as SYCL and OpenACC.

## Requirements

## Learning Outcomes

* Distinguish between Shared Memory architecture, synchronization, pipelining, dependencies, and data handling, and highlight their applications.
* Implement examples for the two most commonly used options with POSIX threads and OpenMP.
* Explain the threading model, including thread creation, management, and termination, in shared-memory environments.
* Compare alternative synchronization mechanisms (mutexes, condition variables, barriers, atomics) to determine the most efficient choice for a given computation.
* Apply compiler optimizations to particular applications/benchmarks
* Combine automatic parallelization by the compiler with manual parallelization, and combine vectorization and parallelization
* Explain the execution model of directive-based parallel programming (e.g., OpenMP), including threads, work-sharing constructs, and synchronization semantics.
* Apply parallel loop constructs, sections, and tasks to improve application performance.
* Assess the applicability of parallel language extensions like CUDA as well as their interoperability (e.g., combining OpenACC and CUDA).
* Understand Language Extensions, remember SYCL and OpenACC and compare the language extension to other concepts, such as processes, vectorizations, and Threading with OpenMP and Pthreads
